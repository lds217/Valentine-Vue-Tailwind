# 💝 Valentine's Day Special - Our Love Journey

A beautiful, interactive web application built with Vue.js and Tailwind CSS to document and celebrate our love journey. This project combines personal sentiment with modern web development practices, creating an engaging user experience through advanced animations and interactive elements.

## 🌟 Features

- **Interactive Timeline**: Visualize our journey together using a GitHub-style contribution calendar
- **Dynamic Photo Gallery**: Responsive image grid with lightbox functionality
- **Floating Hearts Animation**: Beautiful particle-like hearts that float up with parallax effects
- **Love Story Scrapbook**: Animated sections that reveal our precious moments
- **Background Music Player**: Custom audio player with volume control
- **Responsive Design**: Fully responsive layout that works on all devices

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/lds217/Valentine-Vue-Tailwind.git
   ```

2. Install dependencies:
   ```bash
   cd Valentine-Vue-Tailwind
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
